# **App Name**: AdFlow Zone

## Core Features:

- User Login: Streamlined user login for account managers with secure authentication.
- Modular Checklist Builder: A builder tool to define, schedule, and manage recurring maintenance tasks for ad accounts.
- Client Account Task Assignment: A tool to associate clients' accounts to assigned maintenance tasks.
- White-Label Client Portal: A secure portal where clients can log in to view reports branded with their logo.
- KPI Reporting: Display of a few customizable, key performance indicators (KPIs) within the client portal.
- AI Report Summary: AI generates a high-level summary of the ad performance reports for client presentation.

## Style Guidelines:

- Primary color: bright-green for a sense of growth and professionalism.
- Background color: Off-white (#F5F5DC) to ensure a clean and comfortable working environment.
- Accent color: Soft yellow (#E2D474) to highlight key interactive elements without overwhelming the user.
- Headings font: 'Alegreya', serif, to enhance a professional and aesthetically pleasing experience.
- Body font: 'Inter', sans-serif, providing clear readability in a workspace context.
- Use simple, geometric icons for task management and navigation, ensuring clarity and ease of use.
- A desktop-focused layout that follows the 'one thing at a time' principle.
